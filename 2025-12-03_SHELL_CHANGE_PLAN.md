# Shell Migration Plan

**Date:** 2025-12-03
**Status:** Phases 1-6 Complete, Trial Period in Progress

## Goal

Migrate from bash to a modern shell setup:
- **zsh** as login shell (POSIX-compatible, macOS default, safe)
- **fish** and **nushell** installed for interactive trial
- **bash** remains functional for scripts

---

## 1. Shell Strategy

### Decision

| Role | Shell | Why |
|------|-------|-----|
| **Login shell** | zsh | POSIX-compatible, macOS default, safe for system scripts |
| **Interactive trial A** | fish | Best out-of-box UX, 20 years mature, great for daily shell tasks |
| **Interactive trial B** | nushell | Powerful data manipulation, modern paradigm, worth exploring |
| **Scripts** | bash/zsh | Portability, CI compatibility |

### Why This Approach

- **zsh as login shell**: macOS bash is stuck at v3.2 (2007). Need to migrate. zsh is safe, POSIX-compatible, and already the macOS default.
- **Trial both fish and nushell**: Each has strengths. Fish is polished for traditional shell use. Nushell is powerful for data exploration. Try both, decide later.
- **Keep bash working**: Scripts, CI, colleagues' machines all expect POSIX.

## 2. Terminal Recommendations

### Candidates Considered

| Terminal | Performance | Features | Native macOS | Notes |
|----------|-------------|----------|--------------|-------|
| **Ghostty** | Fastest | Modern | Yes (SwiftUI) | By Mitchell Hashimoto (Terraform creator) |
| **Kitty** | Very fast | Most features | No | "Terminal as platform", image protocol |
| **Alacritty** | Very fast | Minimal | No | No ligatures, no images |
| Apple Terminal | Baseline | Basic | Yes | Always works |
| iTerm2 | Slow | Feature-rich | Yes | Heavy, slow startup |
| Warp | Medium | AI features | Yes | Electron-based, privacy concerns |

### Recommendation: **Ghostty** (primary) + Apple Terminal (fallback)

**Why Ghostty:**
- 4x faster than iTerm2 and Kitty for text rendering ([source](https://medium.com/@dynamicy/choosing-a-terminal-on-macos-2025-iterm2-vs-ghostty-vs-wezterm-vs-kitty-vs-alacritty-d6a5e42fd8b3))
- Native macOS feel (Metal rendering, real menus)
- Supports Kitty Graphics Protocol (images in terminal)
- Sensible defaults, minimal config needed
- Font ligatures supported

**Install:** `brew install --cask ghostty`

**Fallback:** Apple Terminal always works and ships with macOS.

│   │   ├── config.nu            # Nushell config

│   └── starship.toml            # Cross-shell prompt config

### Symlinks Created by `setup-shell-symlinks`

```bash

~/.zprofile -> ~/.icloud-drive/dotfiles/.zprofile
~/.aliases.nu -> ~/.icloud-drive/dotfiles/.aliases.nu
~/.config/fish -> ~/.icloud-drive/dotfiles/config/fish
~/.config/nushell -> ~/.icloud-drive/dotfiles/config/nushell
~/.config/ghostty -> ~/.icloud-drive/dotfiles/config/ghostty

```

### Compatibility Strategy

| File | Purpose | Used By |
|------|---------|---------|
| `.profile` | Legacy bash config | bash (keep working) |
| `.zprofile` | Zsh login profile | zsh login |
| `.zshrc` | Zsh interactive config | zsh |
| `.shell-common.sh` | Shared ENV vars (PATH, etc.) | Sourced by bash/zsh |
| `.aliases.sh` | POSIX aliases | Sourced by bash/zsh |
| `.aliases.fish` | Fish aliases | Sourced by fish |
| `.aliases.nu` | Nushell aliases | Sourced by nushell |
| `config/fish/config.fish` | Fish config | fish |
| `config/nushell/env.nu` | Nushell environment | nushell |
| `config/starship.toml` | Prompt config | All shells via starship |

## 5. Zsh Plugin Manager & Plugins

### Plugin Manager: **Antidote**

Chosen over alternatives:
- **vs Sheldon**: Same performance, but Antidote is simpler (plain text config vs TOML)
- **vs Zinit**: Antidote is simpler; Zinit's Turbo mode is overkill for our minimal plugin set
- **vs oh-my-zsh**: Antidote is faster, no framework bloat

**Plugin discovery**: [awesome-zsh-plugins](https://github.com/unixorn/awesome-zsh-plugins) (17k+ stars)

### Plugins to Install

```text
# .zsh_plugins.txt

# Essential
zsh-users/zsh-autosuggestions      # Fish-like suggestions from history
zsh-users/zsh-syntax-highlighting  # Color commands as you type
zsh-users/zsh-completions          # Additional completions

# Nice to have
zsh-users/zsh-history-substring-search  # Better history search
ajeetdsouza/zoxide                      # Smart directory jumping (replaces z)
```

### Prompt: **Starship**

Cross-shell prompt (works in zsh, fish, nushell). Config to match current ps1:

```toml
# ~/.config/starship.toml

[character]
success_symbol = '[💚](green)'
error_symbol = '[💔](red)'

[directory]
truncation_length = 3
truncation_symbol = '…/'
truncate_to_repo = false

[git_branch]
format = '[$symbol$branch]($style) '

[git_status]
format = '([$all_status$ahead_behind]($style) )'
style = 'red'
```
